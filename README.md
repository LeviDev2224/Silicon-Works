---

## 💡 About The Project

Created during a two-week learning sprint, **Silicon-Works** served as a hands-on project to level up web design capabilities, DOM manipulation, state management, and interactive UI component design.

### Key Features
* ⚙️ **Crafting System:** In-game resource gather/crafting mechanics driven by pure vanilla JavaScript (`game.js`).
* 🎨 **Custom UI & Styling:** Modern dashboard layout polished with vanilla CSS (`style.css`).
* ⚡ **Zero Dependencies:** Built entirely with native web technologies—no heavy frameworks required.
* 🚀 **Instant Play:** Deployed directly via GitHub Pages for seamless browser access.

## 🛠️ Local Setup & Development

No build steps or dependency installations are required to run or modify this project locally.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/LeviDev2224/Silicon-Works.git
   cd Silicon-Works
   ```

2. **Run locally:**
   * Open `index.html` directly in any modern web browser, or use VS Code's **Live Server** extension for real-time live reloading.
